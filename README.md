# EC Music Player
Reproductor musical local para Android, desarrollado con Kotlin y Jetpack Compose.

- Biblioteca local mediante MediaStore.
- Reproducción de archivos de música del dispositivo.
- Controles anterior, siguiente, pausa y reproducción.
- Repetición desactivada, repetir una vez y repetir continuamente.
- Reproducción aleatoria.
- Ecualizador Android cuando el dispositivo lo admite.
- Listas de reproducción locales.
- Interfaz oscura con acentos violeta y cian.

Compilar: `gradle --no-daemon :app:assembleDebug`
