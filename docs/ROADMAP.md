# EC Studio roadmap

## Milestone 0.1 — Desktop foundation
- [x] Native JUCE application shell
- [x] Audio device initialization
- [x] Single stereo input recording buffer
- [x] Basic playback and transport
- [x] WAV export
- [x] Timeline waveform overview

## Milestone 0.2 — Session workflow
- [ ] Create, save, and reopen sessions
- [ ] Multiple audio tracks
- [ ] Non-destructive clip placement and trimming
- [ ] Input/output routing and device preferences
- [ ] Metronome and tempo/time signature

## Milestone 0.3 — Editing and mixing
- [ ] Split, move, duplicate, and fade clips
- [ ] Per-track gain, pan, mute, and solo
- [ ] Mixer panel and master bus
- [ ] Undo/redo

## Milestone 0.4 — MIDI and instruments
- [ ] MIDI tracks and piano roll
- [ ] Virtual instrument hosting
- [ ] AU and VST3 effect/instrument hosting

## Later
- Automation lanes
- Time stretching and pitch tools
- Export formats and render settings
- Plugin scanning, presets, and project portability
